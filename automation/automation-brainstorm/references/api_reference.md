# Common App Integration Patterns

Quick reference for the most popular apps people automate with, organized by what they're typically used for. Load this reference when helping a user identify which apps and triggers/actions to use.

## CRM & Sales
| App | Common Triggers | Common Actions |
|-----|----------------|----------------|
| HubSpot | New contact, deal stage change, form submission | Create/update contact, create deal, send email |
| Salesforce | New lead, opportunity update, case created | Create record, update field, add to campaign |
| Pipedrive | New deal, deal stage change, new person | Create deal, update deal, create activity |

## Forms & Surveys
| App | Common Triggers | Common Actions |
|-----|----------------|----------------|
| Typeform | New response | (trigger only — feeds into other apps) |
| Google Forms | New response | (trigger only) |
| JotForm | New submission | (trigger only) |
| Tally | New submission | (trigger only) |

## Communication
| App | Common Triggers | Common Actions |
|-----|----------------|----------------|
| Gmail | New email, new labeled email | Send email, create draft, add label |
| Slack | New message in channel, new reaction | Send message, send DM, create channel |
| Microsoft Teams | New message, new channel | Send message, create channel |
| Twilio | New SMS received | Send SMS |

## Spreadsheets & Databases
| App | Common Triggers | Common Actions |
|-----|----------------|----------------|

| Excel (OneDrive) | New row | Add row, update row |
